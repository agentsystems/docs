# Quick Start

Get AgentSystems up and running in 5 minutes. This guide walks you through installation, setup, and running your first agent.

<Info>
  **Prerequisites**: You'll need Docker installed on your system. The installation script will check for this and help you install it if needed.
</Info>

## Installation

<Steps>
  <Step title="Run the Installation Script">
    Open your terminal and run:

    <CodeGroup>
      ```bash macOS/Linux
      curl -fsSL https://github.com/agentsystems/agentsystems/releases/latest/download/install.sh | sh
      ```

      ```bash Alternative (wget)
      wget -qO- https://github.com/agentsystems/agentsystems/releases/latest/download/install.sh | sh
      ```
    </CodeGroup>

    The script will:
    - Check system requirements
    - Install the AgentSystems CLI (`agentsystems`)
    - Verify Docker is available
    - Set up necessary dependencies
  </Step>

  <Step title="Create Your Deployment">
    Initialize a new AgentSystems deployment:

    ```bash
    agentsystems init my-deployment
    ```

    When prompted, you can:
    - Accept the default directory name or choose your own
    - Optionally configure Langfuse for observability (press Enter to skip)

    Then navigate to your deployment:

    ```bash
    cd my-deployment
    ```
  </Step>

  <Step title="Start the Platform">
    Launch AgentSystems with a single command:

    ```bash
    agentsystems up
    ```

    This command:
    - Starts all platform services (gateway, database, UI)
    - Pulls required Docker images
    - Sets up networking and volumes
    - Waits for services to be ready

    <Note>
      First-time startup may take a few minutes as Docker images are downloaded. Subsequent starts are much faster.
    </Note>
  </Step>

  <Step title="Access the Web Interface">
    Once the platform is running, open your browser to:

    ```
    http://localhost:18080
    ```

    You'll see the AgentSystems dashboard showing:
    - System status
    - Available agents
    - Recent executions
    - Quick actions
  </Step>

  <Step title="Run Your First Agent">
    The platform includes a `hello-world-agent` for testing. Run it using either method:

    **Option 1: Web UI**
    1. Click on "Agents" in the navigation
    2. Find the hello-world-agent card
    3. Click to open agent details
    4. Click "Execute" to run the agent

    **Option 2: CLI**
    ```bash
    agentsystems run hello-world-agent
    ```

    The agent will:
    - Start its container (if not running)
    - Process the request
    - Return results with historical events
  </Step>
</Steps>

## What Just Happened?

When you ran these commands, AgentSystems:

1. **Deployed a complete platform** including:
   - API Gateway (port 18080)
   - PostgreSQL database for audit logs
   - Web UI for management
   - Docker network for agent communication

2. **Configured the environment** with:
   - Default agent registry connections
   - Artifact storage volumes
   - Security policies

3. **Prepared for agent execution** by:
   - Setting up container orchestration
   - Initializing the audit system
   - Creating execution contexts

## Common Commands

Here are the most useful commands for managing your deployment:

```bash
# View platform status
agentsystems status

# Stop the platform
agentsystems down

# Restart services
agentsystems restart

# View logs
agentsystems logs

# Update platform
agentsystems update
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Port 18080 is already in use">
    Another service is using port 18080. Either:
    - Stop the conflicting service
    - Or modify `docker-compose.yml` to use a different port
  </Accordion>

  <Accordion title="Docker is not running">
    Start Docker Desktop (macOS/Windows) or the Docker daemon (Linux):
    ```bash
    # macOS
    open -a Docker

    # Linux
    sudo systemctl start docker
    ```
  </Accordion>

  <Accordion title="Permission denied errors">
    On Linux, you may need to add your user to the docker group:
    ```bash
    sudo usermod -aG docker $USER
    newgrp docker
    ```
  </Accordion>

  <Accordion title="Slow first startup">
    Initial setup downloads several Docker images. This is normal and only happens once. Subsequent starts are much faster.
  </Accordion>
</AccordionGroup>

## System Requirements

<Tabs>
  <Tab title="Minimum">
    - **OS**: macOS, Linux, or Windows with WSL2
    - **CPU**: 2 cores
    - **RAM**: 4 GB
    - **Disk**: 10 GB free space
    - **Docker**: Version 20.10 or later
    - **Python**: 3.11 or later
  </Tab>

  <Tab title="Recommended">
    - **OS**: macOS or Ubuntu Linux
    - **CPU**: 4+ cores
    - **RAM**: 8 GB or more
    - **Disk**: 20 GB free space
    - **Docker**: Latest stable version
    - **Python**: 3.11 or later
    - **Network**: Stable internet for pulling images
  </Tab>
</Tabs>
