AgentSystems configuration follows a clear dependency chain. Each step builds on the previous one.

<Warning>
The hello-world agent typically works without additional configuration, but all other agents require AI provider setup.
</Warning>

## Configuration Dependency Chain

<Steps>
  <Step title="Set Credentials">
    Add API keys for AI providers and container registries

    Navigate to **Configuration → Credentials** in the UI
  </Step>

  <Step title="Configure Model Connections">
    Connect to AI providers using your credentials

    Navigate to **Configuration → Model Connections** in the UI
  </Step>

  <Step title="Configure Registry Connections">
    Set up container registries to pull agent images

    Navigate to **Configuration → Registry Connections** in the UI
  </Step>

  <Step title="Deploy Agents">
    Select and deploy agents from configured registries

    Navigate to **Configuration → Agents** in the UI
  </Step>
</Steps>

## Configuration Methods

<Tabs>
  <Tab title="UI (Recommended)">
    Use the AgentSystems UI at http://localhost:3001

    The UI provides:
    - Visual configuration forms
    - Validation and error checking
    - Immediate feedback
    - No file editing required
  </Tab>

  <Tab title="Manual Files">
    Edit configuration files directly:

    **`.env`** - API keys and credentials
    ```bash
    OPENAI_API_KEY=sk-...
    ANTHROPIC_API_KEY=sk-ant-...
    ```

    **`agentsystems-config.yml`** - Platform configuration
    ```yaml
    config_version: 1
    model_connections:
      # Model configs
    registry_connections:
      # Registry configs
    agents:
      # Agent deployments
    ```
  </Tab>
</Tabs>

## Configuration Files Location

Configuration files are stored in your deployment directory:

```
my-deployment/
├── .env                      # API keys and credentials
├── agentsystems-config.yml   # Platform configuration
└── docker-compose.yml        # Service definitions
```

<Note>
After making configuration changes, restart the platform with `agentsystems restart` for changes to take effect.
</Note>
