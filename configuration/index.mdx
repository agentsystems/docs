## Configuration File

The main configuration file is `agentsystems-config.yml`:

```yaml
config_version: 1

# Model connections
model_connections:
  gpt-4:
    hosting_provider: "openai"
    hosting_provider_model_id: "gpt-4"
    auth:
      api_key_env: "OPENAI_API_KEY"

# Registry connections
registry_connections:
  dockerhub:
    url: "docker.io"
    auth:
      method: "none"

# Agent definitions
agents:
  - name: "hello-world-agent"
    repo: "agentsystems/hello-world-agent"
    tag: "latest"
```

## Environment Variables

Sensitive credentials are stored as environment variables in `.env`:

```bash
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
```
