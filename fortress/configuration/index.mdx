AgentSystems offers two ways to add agents: browse community indexes or configure agents directly.

<Note>
Most agents require AI provider configuration via Model Connections.
</Note>

## Configuration Paths

<Tabs>
  <Tab title="Via Index Connections">
    **Browse and discover community agents**

    <Steps>
      <Step title="Set Credentials">
        Add API keys for AI providers

        Navigate to **Configuration → Credentials**
      </Step>

      <Step title="Configure Model Connections">
        Connect to AI providers using your credentials

        Navigate to **Configuration → Model Connections**
      </Step>

      <Step title="Add Index Connections">
        Connect to community agent indexes

        Navigate to **Configuration → Index Connections**
      </Step>

      <Step title="Browse Agents">
        Discover and add agents from indexes

        Navigate to **Discover** to browse available agents
      </Step>
    </Steps>
  </Tab>

  <Tab title="Direct Configuration">
    **Manually configure agents from known images**

    <Steps>
      <Step title="Set Credentials">
        Add API keys for AI providers and container registries

        Navigate to **Configuration → Credentials**
      </Step>

      <Step title="Configure Model Connections">
        Connect to AI providers using your credentials

        Navigate to **Configuration → Model Connections**
      </Step>

      <Step title="Configure Registry Connections">
        Set up container registries to pull agent images

        Navigate to **Configuration → Registry Connections**
      </Step>

      <Step title="Add Agent Connections">
        Configure agent deployments from container images

        Navigate to **Configuration → Agent Connections**
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Configuration Methods

<Tabs>
  <Tab title="UI">
    Use the AgentSystems UI at http://localhost:3001

    The UI includes:
    - Visual configuration forms
    - Form validation
    - Direct file management
  </Tab>

  <Tab title="Manual Files">
    Edit configuration files directly:

    **`.env`** - API keys and credentials
    ```bash
    OPENAI_API_KEY=sk-...
    ANTHROPIC_API_KEY=sk-ant-...
    ```

    **`agentsystems-config.yml`** - Platform configuration
    ```yaml
    config_version: 1
    model_connections:
      # Model configs
    registry_connections:
      # Registry configs
    agents:
      # Agent deployments
    ```
  </Tab>
</Tabs>

## Configuration Files Location

Configuration files are stored in your deployment directory:

```
my-deployment/
├── .env                      # API keys and credentials
├── agentsystems-config.yml   # Platform configuration
└── docker-compose.yml        # Service definitions
```

<Note>
After making configuration changes, restart the platform with `agentsystems restart` for changes to take effect.
</Note>
